# 数据格式

snapshot_id 是不透明身份，parent 指向直接父版本。current.json 的 version 用于条件更新。快照只列当前活跃文件，partition 是完整字段元组。写入意图的 read_files 与 read_partitions 表示计算所依赖的内容范围，replace_files 是被替换文件；add_files 的路径指向已生成的数据。data 目录的相对路径按湖表根解释。当前工具校验并查看单份清单，不修改 current。

样例均由人工构造，不包含真实机构记录。fixtures/manifest.json 保存原件长度和摘要。文中路径相对于相应样例根目录解释；runtime 保存本地生成数据，不纳入版本管理。
